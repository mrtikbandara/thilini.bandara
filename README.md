# Dr. Thilini — Ayurveda Doctor Portfolio

A modern React + Vite portfolio website focused exclusively on Dr. Thilini Mapa Rallage's Ayurveda medical background, clinical expertise, education, research and professional contact details.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The site is responsive and suitable for deployment to GitHub Pages, Netlify, Vercel or other static hosting platforms.
